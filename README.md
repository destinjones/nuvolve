# Nuvolve CRM

The landing page and live demo of Nuvolve, the pest control CRM: **https://destinjones.github.io/nuvolve/**

Launch the demo company, Lone Star Pest Pros, and log in as any role. The password for every login is `demo1234`.

| Login | What you see |
| --- | --- |
| `owner@demo.com` | Everything: Today, insights, payroll, QuickBooks, marketing, settings |
| `office@demo.com` | Office rep: customers, schedule, billing, inbox |
| `manager@demo.com` | Branch manager for Plano / Allen only |
| `mike@demo.com` | The technician's phone app |
| `sales@demo.com` | The door-to-door sales app |

This repository holds only the built site. It is the real Nuvolve app, answering from a recording of the demo company, so it runs without a server and changes aren't saved. It is built by `demo/build.js` in the Nuvolve CRM repository.
